# uuBright Console support

Use [GitHub Issues](https://github.com/thinkinginmath/uubright-console-support/issues) to report a bug or ask a question about the [uuBright Console beta](https://console.uubright.com/).

Include your Console version, operating system, where Console is running, the steps to reproduce, and what you expected to happen. Issues are public. Remove API keys, pairing tokens, private repository names, prompts, and other sensitive details from screenshots and logs. Email support@uubright.com for private reports.
